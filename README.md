# An RTMB-based Generalized Model for Assessing Crustacean Stocks (GMACS)

### UNDER DEVELOPMENT!

When operational, rtmbGMACS will be a replacement for [GMACS](https://github.com/GMACS-project), the Generalized Model for Assessing Crustacean Stocks, which was developed using [AD Model Builder](https://www.admb-project.org) and has been used to conduct stock assessments for crab stocks in Alaska managed by the North Pacific Fishery Management Council ([NPFMC](https://www.npfmc.org)).
