addGroupIndices: Add group indices to a data frame

Description

Adds an integer column identifying the group to which each row belongs. Groups are defined by one or more columns and follow the grouping behavior of [dplyr::group_by()].

Usage 

addGroupIndices(dfr, ...)

Arguments

dfr

A data frame containing the grouping columns.

…

Unquoted columns in ‘dfr’ that define the groups. These arguments are passed to [dplyr::group_by()].

Value

‘dfr’ with its rows and existing columns preserved and an integer ‘.gid’ column appended. Rows with the same values of the grouping columns receive the same group index. An existing ‘.gid’ column is replaced.

Examples 

y <- as.character(11:20)
s <- as.character(1:3)
x <- as.character(1:2)
z <- seq(25, 50, 5)
dfr <- tidyr::expand_grid(y, s, x, z)

dfrp <- addGroupIndices(dfr, y, s, x)
head(dfrp)
dplyr::count(dfrp, y, s, x, .gid)

createAggregationMatrix: Create a sparse aggregation matrix

Description

Creates a sparse matrix that maps rows of a data frame to groups defined by one or more columns. Multiplying the matrix by a vector with one value per input row calculates sums for each group.

Usage 

createAggregationMatrix(dfr, ...)

Arguments

dfr

A data frame containing the grouping columns.

…

Unquoted columns in ‘dfr’ that define the groups. These arguments are passed to [dplyr::group_by()].

Value

A named list with two elements:

‘aggM’

A sparse matrix with one row per group and one column per row of ‘dfr’.

‘aggTbl’

A data frame containing the unique grouping combinations, in the same order as the rows of ‘aggM’.

Examples 

y <- as.character(11:20)
s <- as.character(1:3)
x <- as.character(1:2)
z <- seq(25, 50, 5)
dfr <- tidyr::expand_grid(y, s, x, z)

lst <- createAggregationMatrix(dfr, y, s, x)
values <- as.matrix(dfr["z"])
group_sums <- lst$aggM %*% values

lst$aggTbl |> dplyr::mutate(sum=as.vector(group_sums));

evalTextAsDataframe: Evaluate a character vector as a dataframe (a tbl_df)

Description

Function to evaluate a character vector as a dataframe (a tbl_df).

Usage 

evalTextAsDataframe(char_vec, comment = "#")

Arguments

char_vec

  • character vector to parse/evaluate as a dataframe

comment

  • string indicating that what follows is a comment

Details

Each element in char_vec is regarded as a line of text (as in a text file). The dataframe structure and column types are determined by readr::read_table().

This function differs from extractDataframe() in that, after comments are removed are removed from the input character vector char_vec, the resulting character vector is regarded as defining the dataframe. In extractDataframe(), the input character vector may be a much larger section of text than what defines the dataframe to be extracted, but the number of rows (n) to extract is known as, is the index of the element to begin with (start).

Value

a dataframe (actually a tbl_df, see tibble::tibble())

Examples 


# example code
str<-paste0('
  id        function  frame   params              description
  pwrLaw1   pwrLaw1   mfALL   pA,pB               w(z)_=_pA_*_(z^pB)
  pwrLaw2   pwrLaw2   mf2024  pLnA,pLnS,pB,pZ0    w(z)_=_exp(pLnA+pLnS+pB*ln(z/pZ0))
')

evalTextAsList: Evaluate a list from a character vector

Description

Function to evaluate a list from a character vector.

Usage 

evalTextAsList(strv, split = "<-", verbose = FALSE)

Arguments

strv

  • character vector to parse/evaluate

split

  • character(s) to use to split lines into name and value (default="<-")

verbose

  • flag to print diagnostic info

Details

Each quantity assigned using ⁠<-⁠ in strv is interpreted as an equation defining an element of the returned list. Quantities assigned using = outside a list structure are evaluated locally for use in constructing a list element of the returned list. Attributes for a list element of the returned list must be assigned (see example code 2) immediately after the list element.

Value

list with named elements

Examples 


# example code 1
str=paste(
  'MODEL_DIMS
  y <- 2020:2024;                           #--years
  s <- 1;                                   #--seasons
  r <- "EBS";                               #--regions

  m <- c("immature","mature");              #--maturity state classes
  p <- c("new_shell","old_shell");          #--post-molt ages
  zc <- seq(55.5,104.5,5);                  #--size bin cutpoints
  f <- c("TCF","SCF","NMFS");               #--fleets
  END');
strv = str |> splitText() |> extractLines("MODEL_DIMS","END");
lstDims = evalTextAsList(strv);

extractNumericValue: Extract a numeric value from a line of text

extractTextAfterString: Extract text after a string

Description

Function to extract text after a string

Usage 

extractTextAfterString(txt, str)

Arguments

txt

  • character vector from which to extract strings

str

  • string to extract after (see NOTE under details)

Details

For each element in the vector, this extracts the string following the ‘after’ string from each element of the input character vector, or ‘NA’ if no ‘after’ string found.

NOTE: Characters with special regex meanings (e.g., ")","]") need to be double-escaped to use in ‘str’.

Value

character vector of extracted strings

Examples 

# example code
extractTextAfterString("test:fred[x,y]==0","==");
extractTextAfterString(c("fred[x,y]==0: FALSE","b[z0]: 1"),":");
extractTextAfterString("fred[x,y[z]]=0","=");
extractTextAfterString("fred[x,y[z]]=0","\\[");
extractTextAfterString("fred[x,y[z]]=0","fred\\[");
